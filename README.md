# williamchen-pm.github.io

### ▶ [View the live site](https://williamchen-pm.github.io/)

Personal site and portfolio. Product management work across platforms, developer tooling, and applied AI, with links to the working prototypes behind it.

---

## What's here

A single static page covering the platform work I've led, how I approach requirements, validation, and release, what I own beyond the roadmap, and the six prototypes I built. No framework, no build step, no dependencies beyond web fonts.

`index.html` is the whole site. Roughly 60KB, one file.

## Built with

HTML, CSS, and vanilla JavaScript. Served by GitHub Pages.

Typography is Archivo, Source Serif 4, and JetBrains Mono. Everything is responsive down to mobile, meets WCAG AA contrast, and respects `prefers-reduced-motion`.
